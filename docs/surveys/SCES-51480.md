# Network survey: SCES-51480

| | |
|---|---|
| Volume | TMBO |
| Boot executable | `SCES_514.80` |
| Video mode | PAL |
| Executable | entry 0x00100008, 2,236,548 bytes of code, stripped |
| Online stack | yes |

## What the online mode needs

- Ethernet adapter: emulate DEV9 + SMAP under the IOP so the disc's own DEV9/SMAP/INET modules run (or replace the INET stack with HLE).
- PPP/PPPoE modules are present; DHCP over Ethernet is usually enough, PPPoE can stay unused.
- Network configuration: the game reads a configuration file (memory card BWNETCNF or HDD); provide one or synthesize what netcnf returns.
- libnet over mSIF RPC: the EE talks to LIBNETB.IRX through MSIFRPC.IRX (IOP kernel needs thmsgbx).
- DNAS: skip the authentication with a function override, or point it to a revival DNAS server.
- Medius: Revival servers exist for several Medius titles; the wire protocol is the same for every game.
- SSL/TLS: Expect certificate checks to need a bypass or a local TLS terminator.
- DNS overrides for the original servers: tmbonline.scea.com, tmbol-master.online.scee.com
- Players host matches (peer to peer): the host needs inbound connectivity, so the NAT layer must forward ports and the address the game reports may need fixing.
- HDD modules are present (optional for most games; some read the network configuration there).
